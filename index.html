Git Revenge packages

Repositories for Git Revenge, the fast, local-only desktop git client. Add one once, and it updates with the rest of your system.

Add the repository

Ubuntu and Debian

Ubuntu 24.04 or Debian 13, or newer.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/gitrevenge.asc \
  https://packages.gitrevenge.com/gitrevenge.asc
sudo tee /etc/apt/sources.list.d/gitrevenge.sources >/dev/null <<'EOF'
Types: deb
URIs: https://packages.gitrevenge.com/apt
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/gitrevenge.asc
EOF
sudo apt update && sudo apt install gitrevenge

RHEL, AlmaLinux and Rocky Linux

Versions 9 and 10. On 10, turn on EPEL first: sudo dnf install epel-release, or on RHEL, the steps in the install guide.

sudo curl -fsSLo /etc/yum.repos.d/gitrevenge.repo \
  "https://packages.gitrevenge.com/rpm/gitrevenge-el$(rpm -E %rhel).repo"
sudo dnf install gitrevenge

dnf asks you to accept the key the first time. Check its fingerprint below.
